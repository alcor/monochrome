## Microsoft Edge

- Monochrome works with Microsoft Edge (and Edge Beta, Dev and Canary) as it does with Chrome: locked tabs and the Locked group, ⌃Tab, mini and peek browsers, the command bar, the mini player and the profile hotkeys.
- Choose Edge in Settings → Browser. Links from other apps then open in Edge, Edge starts at login with the launch flag, and the Dock tile takes Edge's place.
- Install Extension… opens `edge://extensions` when Edge is the browser.
- ⌥⌘↓ and ⌥⌘↑ step through Edge's tabs. Edge has no menu item to collapse vertical tabs, so ⌘S stays Save Page As there.

## Updates

- Updates install on their own: Monochrome downloads them in the background and relaunches when its settings window is closed. Turn this off in Settings → General → Install updates automatically.
- Release notes now show in the update window.

## Fixes

- The close-tab command closes a New Tab page in Edge, which refuses to let an extension close one directly.
